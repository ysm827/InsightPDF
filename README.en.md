## Overview

A Gemini multimodal document assistant for chatting with PDFs and seeing where answers come from on the page.

## Features

- Chat-based PDF question answering.
- Visual grounding and bounding-box highlights.
- Supports free demo and custom API-key modes.
- Frontend built with React and Vite.

## Quick Start

- Enter `insightpdf`.
- Run `npm install`.
- Configure a Gemini API key and run `npm run dev`.

## Configuration

- Requires a Gemini API key; PDF processing and model options are controlled by app configuration.

## Tech Stack

- React

- Vite
